## 1. Who ran it, and what that does and does not show

The owner asked the build agent on 2026-11-10 to run `docs/v2/M5B_PERSONA_WALKTHROUGH.md` on their behalf. So this is **not**
an owner-run walkthrough and **not** buyer feedback:

- **The clicking** was done by a script in a real Chromium (1280x900): it clicked each free cached example question on the live
  preview, opened every citation chip (up to 14 per answer) and recorded the answer, the badges and the evidence text.
- **The scoring** was done by model agents, one per persona, each reading the recorded evidence and the screenshots against
  the walkthrough's own 'Good' and 'Red flags' lines. A separate agent audited numbers, hedges and attribution without seeing
  the persona scores, and the one score of 2 was re-checked by a second agent. I checked the most serious page findings myself.
- **Three first-time-visitor readings** (section 4) were added at the owner's request ('even a noob should grasp this site'):
  agents with no knowledge of the project, shown only screenshots and page text.
- **Limits.** Model agents are not analysts and not buyers; they cannot judge willingness to pay or spot a subtly weak answer
  the way a domain expert would. The recorder kept only the first 2,600 characters of each evidence panel, so several
  'could not confirm' notes below are limits of the recording, not findings about the site. P8 stays recorded as
  **persona walkthrough; real-buyer feedback pending**, now with the note that an agent ran it for the owner.
