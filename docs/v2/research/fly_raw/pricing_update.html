Sprites pricing

Sprites Compute

No plans and no tiers, and nothing charged per Sprite. Metered per hour of active use.

Resource Rate
CPU time Cumulative CPU usage measured by cpu.stat $0.03825 / CPU-hour
Memory time Actual memory usage $0.021875 / GB-hour

A Sprite running flat out on 2 vCPU and 4GB of memory for a 720-hour month costs $118.08, down from $226.80. You pay for the CPU and memory you actually use, so most workloads land well below that.

Sprites Storage

Billed in GB-hours at two rates, which differ in when they stop.

Tier Rate Per GB-month

Cold Bills for as long as you keep it $0.000027 / GB-hour $0.02

Storage rates are unchanged. Per-month figures are the hourly rate over a 730-hour month.
