## 3. The StateBackend protocol

```python
class Denied(Enum): KILL, DAILY_COUNT, DAILY_SPEND, IP_DAILY, INFLIGHT, UNAVAILABLE
class Lease(NamedTuple): lease_id: str; day: str; ip_hash: str; strategy: str; workspace: bool; estimate_micro: int; until_mono: float; machine_id: str
class StateUnavailable(RuntimeError): ...
class StateBackend(Protocol):
    def reserve(self, *, ip_hash, strategy, workspace, estimate_micro, now_wall, now_mono) -> Lease | Denied
    def mark_started(self, lease_id) -> None        # registry entry: maintenance thread renews it; TTL now covers only never-started streams
    def renew(self, lease_id, now_wall) -> bool     # writes lease_until on the row
    def reconcile(self, lease_id, *, outcome, usage, cost_micro) -> bool   # idempotent; True iff it charged; adjusts lease.day's counters only
    def sweep(self, now) -> int                     # unregistered, expired leases: charge estimate, outcome=abandoned, free in-flight
    def rebuild_from_ledger(self) -> RebuildReport
    def kill_level(self) -> str                     # memory cache; "on" when unread, stale > kill_switch_stale_s, or env override set
    def set_kill_level(self, level) -> None         # memory first (a more restrictive level applies even if the DB write fails), then SvcPolicy
    def cache_get(self, key, ttl_hours) -> dict | None   # raises StateUnavailable
    def cache_put(self, **kw) -> None               # best effort
    def snapshot(self) -> dict                      # {day, paid, spend_micro, inflight, per_ip_max, kill, kill_age_s, leases}
```

**One timeout idiom (replaces `asyncio.wait_for`):** every state call is `await anyio.to_thread.run_sync(fn, limiter=limiters.state)` with NO caller-side timeout; the bound is in the work: the state driver's 0.5 s acquisition / 1 s connect, managed `execute_write`/`execute_read` with `max_transaction_retry_time=state_op_timeout_s`, and `unit_of_work(timeout=state_op_timeout_s)` as the server-side transaction timeout (precedent `agent/tools.py:195-209`). Any driver error or timeout → `StateUnavailable`; wall-clock > 1 s is logged `state_slow`. Threads therefore never pile up, and a reserve never completes after its caller gave up (review item 10 resolved by construction; in-process counters are mutated before the row write and rolled back on its failure, so no orphan lease exists). Cleanup uses the same idiom; `move_on_after` around threads is forbidden (shielded, never fires).

**In-process backend:** one `threading.Lock` over `counters: dict[day, DayCounters(paid, spend_micro, per_ip)]`, `leases`, `started: set`; `reserve` under the lock: kill → KILL; `paid+1 > max` → DAILY_COUNT; `spend+est > cap_micro` → DAILY_SPEND; `per_ip[iph]+1 > 20` → IP_DAILY; `len(leases) >= max_concurrent_answers` → INFLIGHT; else increment and insert; release; durable row via `ledger.reserve_row(...)`; on failure roll back under the lock → UNAVAILABLE. Day counters are keyed by day and kept while any lease references them (a 23:59 lease keeps its slot; its reconcile adjusts day D). `reconcile`: pop lease (absent → False), `counters[lease.day].spend += actual − estimate` (floor 0), then `ledger.settle_row`; failure → 3 retries 2 s apart, else logged and the boot charges the estimate. Caps of 0 are invalid in production and mean "off" elsewhere (`cap == 0 or ...`).

**Neo4j backend (`state/ledger.py` holds all Cypher, worker-owned):** one `execute_write` per reserve: `MERGE SvcDayCounter {day} SET c._lock=true`, `MERGE SvcIpDay {day, ip_hash} SET i._lock=true`, in-flight = `count(SvcQuery {status:'reserved'}) WHERE lease_until > $now` (no day filter), `WHERE` all four caps, `SET` increments, `CREATE SvcQuery {..., estimate_micro, lease_until, machine_id, ip_hash_v}`; zero rows = denied, a read names the cap. `reconcile`: `MATCH (q {id, status:'reserved'}) SET settled ... WITH q MATCH (c {day:q.day}) SET c._lock=true, c.spend_micro = c.spend_micro + $actual_micro − q.estimate_micro` (integers, no float truncation).

**Boot rebuild (both):** (1) expire `status='reserved'` rows with no day filter where `lease_until < now − 2·lease_renew_s` OR `machine_id = $me` → `abandoned_restart`, `cost_micro = estimate_micro`; (2) sums for today over `cached:false` settled rows plus unexpired reserved rows (other machines' live leases are respected, so two neo4j-backend instances share one DB safely — trigger T1); (3) per-IP counts and `rate_limiter.seed(iph, timestamps)` for `ip_hash_v = 2` rows; the neo4j backend reconciles `SvcDayCounter` to the sums only when no unexpired foreign lease exists, otherwise logs the delta. Caches and read windows reset. Freshness "not checked since restart" is a `monitor.summary()` field.

**Failure policy → code points:** `cache_get` raises → 503 `MSG_PAUSED`; `kill_level` unread/stale/env-override → `on`; reserve UNAVAILABLE → 503; reconcile failure → retry queue, else boot charges; `upload_document` uses `kill_level()`; read routes (dossier, risk-changes, evidence) get per-route driver timeouts measured on the local graph and recorded (not the 1 s state bound); `/healthz` keeps its own 5 s path on `limiters.health`.

**Contract tests** (`tests/test_state_contract.py`, parametrised `inprocess|neo4j`; neo4j via the integration marker in the new CI Neo4j job; plus a fake-driver test that `SET _lock` precedes `WHERE`): 200 threads vs cap 150 → exactly 150 granted and 150 rows; spend cap 1.0 with est 0.06 → 16 granted; per-IP 21st denied while another hash passes; in-flight 3rd denied, freed by reconcile; double reconcile charges once; `cost=None` keeps the estimate; sweep charges and frees; renew writes `lease_until`; kill levels and stale cache → KILL; a stream crossing midnight reconciles into its own day and the new day starts at zero; reconcile racing sweep charges once; two backend instances on one DB: instance B's boot does not expire A's live lease and A's reconcile still lands; kill-then-boot snapshot equals the ledger; failed row write rolls counters back; 50×10 reserves vs cap 20 never overshoot; 100 ops against a stalled fake driver each raise `StateUnavailable` ≤ 1.1 s and the thread count stays ≤ limiter size + maintenance; a real-Neo4j test where a `UNWIND range` query with `timeout=0.2` is cut by the server.

## 9. Risks, verification, cleanup, audit, findings not adopted

**9.1 Where the obvious implementation is wrong:** (1) any sync hop inside the async stream blocks the loop — every hop is a thread under a named limiter, proven by the loop-lag monitor in the 40-stream test; (2) `asyncio.wait_for`/`move_on_after` around threads either leak threads or never fire — bounds live in the driver; (3) a task group or cancel scope open across a `yield` breaks on disconnect — finalize is a `BackgroundTask`; (4) `shutdown_grace_period=0` cuts streams at SIGTERM; (5) day-keyed counters reset under live leases — leases carry their day; (6) `RateLimiter` stays loop-only except `seed` before serving; (7) `kill_switch` bool vs level: accept both, `paused` = any non-off; (8) rollback to pre-I4 with `retrieval_only` set reads as off — RUNBOOK rule; (9) the embedder change must not touch queries/templates — G3-style diff; (10) `hf_hub_download` without `revision` silently changes the export — pinned.
